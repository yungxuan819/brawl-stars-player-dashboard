# brawl-stars-player-dashboard
Using Brawl Stars API, I collected data and built an ETL pipeline to store them using SQLite. Then, I obtained and cleaned necessary data, and built a visually appealing dashboard using Tableau, that shows visualizations to allow players to analyze their performances.
